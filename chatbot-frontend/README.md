# Chatbot Frontend

React + Vite frontend for Calisto Module 1.

## Setup

```bash
cd chatbot-frontend
npm install
```

## Development

```bash
npm run dev
```

Set the backend API base URL using:

```
VITE_API_BASE_URL=http://localhost:3000
```

## Pages

- /webchat
- /leads
- /products
- /knowledge
